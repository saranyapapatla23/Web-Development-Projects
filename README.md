# Project 1 — Text Analyzer

A beginner-friendly JavaScript project that allows users to enter text and perform different text manipulation and analysis operations.

## 🎥 Project Demo

https://github.com/user-attachments/assets/63369bce-106f-4f37-b9d9-5333028ad614

## ✨ Features

* Count the total number of characters
* Count characters excluding spaces
* Convert text to uppercase
* Convert text to lowercase
* Extract a portion of text using `slice()`
* Replace text using `replace()`
* Replace all occurrences using `replaceAll()`
* Find the first character
* Find the last character
* Reverse the entered text
* Check whether text contains a specific word
* Check whether text starts with specific text
* Check whether text ends with specific text
* Clear the input and result

* JavaScript

# Project 2 — BMI Calculator

A beginner-friendly BMI Calculator built using HTML, CSS, and JavaScript. The application takes the user's height and weight, calculates their BMI using a JavaScript function, and displays a general BMI status using conditional statements.

## 📸 Project Demo

https://github.com/user-attachments/assets/35aa7b74-8590-4148-8fc1-baa72796f777

## ✨ Features

* Enter height in centimeters
* Enter weight in kilograms
* Calculate BMI
* Display BMI value up to 2 decimal places
* Display general BMI status
* Reset the input and results
* Press Enter after entering height to move to the weight field
* Press Enter after entering weight to calculate BMI

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📚 JavaScript Concepts Practiced

* Functions
* Function parameters
* Return values
* Calling functions
* DOM manipulation
* `getElementById()`
* `addEventListener()`
* `.value`
* `.textContent`
* `Number()`
* `toFixed()`
* `if / else if / else`
* Comparison operators
* Keyboard events
* `event.key`
* `.focus()`

## 🧮 BMI Formula

```text
BMI = weight / (height in meters)²
```

The application converts the entered height from centimeters to meters before calculating BMI.

## 🎯 Purpose

This project was built as part of my JavaScript learning journey to practice functions, return values, conditional statements, DOM manipulation, and user input handling.
